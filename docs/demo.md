# Five-minute demonstration

Prepare the project using the README, then run uv run learning-support demo. Use 2026-03-16 and the two-week window.

1. **Class overview:** the first class has 40 synthetic students. Explain the four temporary groups and the separate insufficient-observation state.
2. **Dynamic profile:** select 演示学生01. Algebra foundation practice is approximately 76%, geometry approximately 41%. Inspect individual knowledge points, then the independent ability tab. A strong domain average does not erase a local gap.
3. **Teaching groups:** inspect each group's typical situation and suggestion. The actual class example is drawn from current synthetic members, rather than invented to illustrate a category.
4. **Teacher review:** select a judgment, actions, reason and follow-up time in the student tab. Save it; optionally review a domain or ability independently. No text entry is required.
5. **Report:** generate and download a class PDF. Confirmed and unconfirmed advice are visibly distinct. Change to a single student and regenerate; the old class download is no longer offered.
6. **Evidence boundary:** change the cutoff to 2026-01-01. All 40 students in the first class need more observation. No missing score becomes zero and no student is forced into a group.

Reviews are demonstration records stored locally. Resetting a demo is not required: use --data-dir and --db with new paths when you need a fresh dataset, and never overwrite a database containing reviews you wish to keep.

The curated sample PDF is a class report with 40 students. It has no real teacher confirmations; suggestions are marked as awaiting review.
