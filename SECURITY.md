# Security and data handling

This is a local synthetic-data prototype, not a production student-information system. It has no accounts or permission model. Do not expose the Streamlit server publicly or use authentic student records.

Only the current public V2 snapshot is maintained. Dependency installation needs network access; the application itself makes no LLM/API calls and disables Streamlit usage telemetry in its configuration.

For a security issue, use GitHub private vulnerability reporting if enabled, or an available private maintainer contact. Do not publish secrets, student data or exploit details in a public issue. If neither private route is available, open a minimal issue requesting a private contact without sensitive details. No guaranteed response time or security audit is claimed.
