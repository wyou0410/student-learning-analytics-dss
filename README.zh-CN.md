# 学生学习分析与干预决策支持系统

[English](README.md) · [方法说明](docs/methods.md) · [验证结果](docs/evaluation.md) · [示例PDF](examples/teacher-report.pdf)

这是一个面向普通初中数学教师的可解释学习分析原型。它用已分配任务和首次有效作答，形成随观察阶段变化的知识点画像、独立能力练习观察、代数/几何四类分组与教学建议，并保留教师复核。

全部学生和作答均为合成数据。项目使用显式规则，不训练预测模型，不调用LLM，不需要API Key或GPU。验证结果只说明工程实现，不能证明真实教学效果。

## 三分钟查看

先看英文首页的界面截图，再打开示例PDF，最后查看验证说明中的手算情境。五个教师入口为班级概览、动态学生画像、教学分组、教师复核、教学报告；没有JSON、哈希和开发者调试记录。

## 运行

提供Python 3.11+与uv，在项目根目录执行：

```bash
uv sync --locked --extra dev
uv run learning-support demo
```

浏览器打开 http://127.0.0.1:8502。首次运行生成资料、校验导入SQLite、分析、导出PDF并启动页面；后续复用数据库，保留复核。端口已占用时加 --port 8503。安装依赖后可以离线运行。

```bash
uv run learning-support demo --no-ui
uv run pytest -q
```

默认资料截止2026-03-16，支持7/14/28天窗口。切到没有合成练习的日期，会显示证据不足；缺失不补零。

## 四类与能力观察

仅代数、几何基础题参与四类分组。每个领域至少5道已评分首次有效作答、至少2个任务，达到演示阈值70%为本阶段较稳，否则需巩固；任一领域证据不足则暂不分组。

四类为双领域较稳、代数需巩固、几何需巩固、双领域需支持。运算/推理/应用来自单独标注的能力练习，不成为第三个分组轴，不从总分反推学生总体能力。领域较稳也可能同时有局部薄弱知识点。

教师复核包含学生、知识板块、能力三个选项卡，判断、行动、依据和时段用预设选项。PDF逐人列出已确认、待确认和暂缓安排；新阶段不会自动继承旧复核。

## 数据、成果与边界

默认80名合成学生，4个代数/6个几何知识点，30道基础题、12道能力题，36个任务与33,298条作答。六个几何知识点为平行线与角、三角形、全等、等腰、勾股定理、四边形。题干、参考答案及标签均可在生成器中核查；未经过课程专家审定或难度标定。

技术成果为可解释规则决策支持、证据追溯、未来数据隔离、教师复核与可读报告。无模型准确率、成绩提升、学校试用或现实教育效果结论。实现、测试和文档使用了Codex协助，详见贡献说明；不能把工具辅助的全部实现表述为独立手写代码。

公开版保留运行必需文件和精选演示材料，排除旧界面、生成数据库、完整CSV、临时日志、开发过程清单和本机路径信息。课程负责人专业验收、教师现实可用性反馈、生产权限管理仍未完成。
